486: [Heading 2] 6.1 Desarrollo
487: [normal] Para dar solución al problema planteado se construyó Agroplaga AI, una aplicación web que ayuda a los agricultores de melocotón a monitorear sus cultivos y detectar a tiempo la presencia de plagas o condiciones ambientales adversas.
488: [normal] El sistema se desarrolló inicialmente en modo local (localhost) para probar la comunicación entre frontend, backend y base de datos. Posteriormente se proyecta que funcione tanto offline como online, de manera que el agricultor pueda registrar y visualizar datos incluso sin conexión a internet, y que al restablecerse la red estos se sincronicen automáticamente con el servidor.
489: [normal] La aplicación incluye módulos principales como el registro y consulta de lecturas de sensores (temperatura, humedad y luminosidad), la gestión de plagas con imágenes de referencia, el historial con exportación a CSV y la configuración de umbrales de alerta que generan notificaciones visuales.
490: [normal] A continuación, se presentan capturas de pantalla del código y de la interfaz gráfica que muestran los elementos clave de la aplicación, así como las pruebas realizadas para verificar su correcto funcionamiento.
492: [Heading 3] 6.1.1 Tecnologías usadas para la aplicación
493: [normal] • Lenguaje de programación frontend: JavaScript
• Framework: React (Vite)
• Backend: Node.js con Express
• Base de datos: MySQL 
• ORM: Sequelize
• Gestión de datos locales: localStorage e IndexedDB (para modo offline)
• Microcontrolador: ESP32 (lectura de sensores)
• Sensores: DHT22 (temperatura y humedad), BH1750 (luminosidad)
• Herramientas de desarrollo: Visual Studio Code, Postman
